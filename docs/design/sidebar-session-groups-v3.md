# 侧栏分组方向与选中样式

**方案 v3 · 已确认 · 2026-11-19**

![Open 由上向下排列，Settled 由下向上排列，仅选中的 Open 行有浅底与细框](sidebar-session-groups-v3.png)

示意图展示短列表、两组展开和一条 Open 会话选中时的效果。

## 布局

- **Open** 标题靠上。按最近活动时间排序，从标题向下依次显示最新、较早、更早的会话。
- **Settled** 标题靠下，位于底部工具栏上方。最新会话贴着标题，从标题向上依次显示最新、较早、更早的会话。展开时标题使用向上箭头。
- 两组都放得下时，中间留出可伸缩空白。内容超过可用高度时，共用一个滚动区，搜索栏和底部工具栏固定。用户主动展开 Settled 时，将该组标题对齐滚动区底边，以露出最近几条会话。打开会话或跨组移动时按会话 ID 定位选中项。
- 两组独立折叠，组标题显示匹配数。折叠时，符合筛选的组内选中项贴近标题显示，Open 在标题下面，Settled 在标题上面。空结果在 Open 标题下方显示提示。

## 行样式

| 状态 | Open 与 Settled |
|---|---|
| 默认 | 会话内容直接排在侧栏背景上。Open 两行，Settled 单行 |
| 悬停 | 短暂显示轻微背景色，边缘融入列表 |
| 选中 | 淡紫底加 0.5 pt 细框。描边采用现有明暗选中边色的 42% 不透明度，只用于侧栏会话行 |
| 键盘焦点 | 系统焦点提示独立显示。VoiceOver 播报选中状态 |

卡片内的项目、会话名、时间、提醒与执行状态按 [v2 方案](sidebar-session-groups-v2.md) 展示。保留行点击区及独立动作。选中、运行、提醒各自有明确提示。

## 实施与验证

- 由一位实现者调整侧栏列表及行样式。投影先按最近活动时间降序及稳定会话 ID 排好，再反向展示 Settled，使两组都能从标题读到最新会话。扩展列表使用现有惰性加载与按 ID 定位。填满可用高度时用中间空白吸收剩余空间，溢出时空白收缩。
- **SB-03** 用宿主测试核对两组排序、同时间的稳定顺序、过滤和折叠选中项。用 macOS 原生样例核对短列表的两端锚定、超长共滚动、展开 Settled、跨组移动和清除搜索。证据绑定本轮实现候选。
- **SB-04** 用明暗截图核对默认、悬停、选中、键盘焦点与运行状态。确认 205 pt 窄侧栏仍可区分选中项，并用键盘和 VoiceOver 核对按钮与行状态。
- 独立 reviewer 核对生产列表入口、两组方向、按 ID 定位与状态样式。若发现回归，实施者修正，独立 reviewer 在新候选上检查受影响路径。原生验证使用隔离数据及获得相应授权的运行环境。

0.5 pt 和 42% 是本轮设计值。静态示意展示布局与视觉层级。长列表行为及明暗外观以原生候选验证为准。
