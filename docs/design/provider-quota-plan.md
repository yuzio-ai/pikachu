# 模型供应商额度：实施计划

## 目标和范围

沿用侧栏底部现有的额度图标，不增加常驻文字。弹层优先展示当前会话实际使用的供应商与账号；额度与会话上下文、累计 Token 用量分开。首版只接一个可验证的数据源，不做余额估算、不接网页私有接口。

## 1. 确认首个提供方

- 优先调研 `openai-codex`：先确认项目实际支持的 Pi 版本是否通过受支持的接口提供**当前账号**的订阅周期、已用或剩余比例、重置时间，以及稳定的账号标识。接受已受支持的 Pi 接口或供应商公开文档，不把网页内用接口当作正式依赖。
- 若不可用，则选择已配置且有官方余额 API 的提供方。DeepSeek API Key 是备选：若在现有接入和认证机制下可用，先接其官方余额接口，按币种显示可用余额；没有预算上限就不显示百分比，没有重置字段就不显示重置时间。若没有符合条件的已接入账号，先交付未支持状态，不用假数据填充。
- 产出一张能力表：提供方、认证方式、可用指标、适用范围、更新时间、查询频率和权限要求。固定接口与去敏响应夹具后再开始适配。

### 实机探针结果：Codex App Server

- 已用本机 Codex CLI `0.167.0` 通过 `app-server --listen stdio://` 完成 `initialize` → `initialized` → `account/read`（`refreshToken: false`）→ `account/rateLimits/read`。Codex 使用自己已有的 ChatGPT 登录；探针没有读取或传出 OAuth token，也未启动模型任务。
- `account/read` 确认账号类型为 `chatgpt`；额度 RPC 实际返回了 `codex` 限额及 `primary.usedPercent`、`primary.windowDurationMins`、`primary.resetsAt`，其中周期为 10,080 分钟（7 天），本次 `secondary` 为 `null`。可用 `100 - usedPercent` 计算该窗口剩余百分比；`resetsAt` 是 Unix 秒。`rateLimits` 与 `rateLimitsByLimitId.codex` 在本次返回中是同一份数据，展示时不重复计入。
- 目前只验证了 **Codex 登录账号的 Codex 限额**，不等于 ChatGPT 网页额度或 API 余额，也未证明 Pi 的 `openai-codex` 正在使用同一账号。若暂时无法核实账号一致性，应独立标注「本机 Codex 账号」，不能套到当前会话或触发该会话的低额提醒。首版可让 Codex 管理自己的 OAuth，应用仅消费必要 RPC 字段，不读 token 文件。

## 2. 定义数据和刷新规则

- 以提供方、账号标识、认证方式和服务端点为缓存范围；同一账号下的不同模型可共用账号额度。模型专属速率限制单独标作用范围。不能确认账号归属时，不跨会话或凭据缓存复用。
- 把指标分为订阅周期额度、货币余额/预算和速率限制。字段按实际数据保存：单位、窗口或周期、观测时间、可选的重置时间；缺失字段不补零。
- 在 Pi 适配层归一化数据，工作台持有查询状态。侧栏只读状态并触发刷新。首版使用内存缓存；不在设置、日志或会话历史中记录凭据，也不把凭据传到 SwiftUI。复用已有授权边界；若无法安全复用，不接该提供方。
- 异步查询：首次看到有效账号时检查；展开弹层时若超过 5 分钟则刷新；手动刷新允许重试，但合并同账号并发请求，并遵守提供方限流。已知窗口到期后自动作废旧值；失败保留上次结果并标记过期。切换账号时只显示新账号的数据，忽略旧请求返回。

## 3. 接入侧栏和验收

- 把侧栏目前传入的空额度列表替换为真实查询状态。弹层显示账号、指标、最近查询和手动刷新；未配置、不支持、加载中、查询失败、结果过期分别说明。未选中会话时不猜测账号。
- 图标默认中性；只有可信且未过期的周期额度剩余 ≤10% 或明确已用尽时提示。货币余额无可信上限时，首版只在官方确认不可用或余额为零时提示，不套用百分比阈值。速率限制不冒充余额，也不触发低余额提醒。
- 单测覆盖版本对应的解析夹具、零值与未知、币种、窗口重置/过期、认证失败、限流、超时、刷新合并、账号切换后迟到响应。用假数据做侧栏布局与 VoiceOver 验证，再用已授权测试账号核对一组真实读数与供应商页面/接口。首版验收通过后，才增加其他提供方或多账号汇总。

## 4. 首版实现记录

- 侧栏入口使用图标呈现，不增加常驻额度文字；数值出现在工具提示、VoiceOver 和弹层中。侧栏出现时首次查询，打开弹层或手动刷新时按 30 秒节流重新查询。查找 Codex CLI 时沿用「服务商 → Pi 连接 → 工具搜索目录」，并补充常见用户级安装目录与继承的 PATH。
- 查询结果在 5 分钟后标为待更新；失败时保留上次结果并标记过期，未找到 CLI、未登录和查询失败分别说明。
- 弹层标题标注「本机 Codex 账号」，显示周期、剩余比例、重置时间与查询时间，并说明额度未与当前会话关联。
- 只在单一窗口的剩余额度 ≤10% 时使用警告图标；额度变化不触发会话级提醒。
- 额度解析夹具与刷新状态见 `Tests/PikachuTests/SessionDetailUITests.swift` 和 `Tests/PikachuTests/SidebarTests.swift`。
