# 工作台对话区卡片

**设计已定稿** · 2026-11-24 · r06

本稿保留为历史版本。当前工作台布局见 [统一底色设计](workbench-unified-background.md)。

左侧栏与窗口顶栏共用一层浅灰底色。对话区用细描边和轻阴影浮在这层底色上。右侧文件预览停靠时，两栏共用一个卡片外框。

## 布局与样式

| 区域 | 定稿规则 |
| --- | --- |
| 窗口底色 | 左侧栏和窗口顶栏共用现有 `ZivviTheme.sidebar`。弱化两者交接处的分界，使底色连续。沿用现有侧栏、顶栏控件、选中态和位置。 |
| 卡片外框 | 在顶栏下方、左侧栏右侧设置一圈圆角细描边，外侧加轻阴影。r06 描边为 2 px，圆角半径为 23 px。原生布局采用 1 pt 描边、12 pt 圆角和 3 pt 外侧留白。描边使用 `ZivviTheme.border`，卡片内沿用对话与文件预览各自的底色。 |
| 对话和文件预览 | 文件预览关闭时，外框包住对话和输入框。文件预览停靠时，外框同时包住右侧预览，两栏之间沿用现有分隔线和拖拽交互。文件标签继续在窗口顶栏。[项目文件设计](project-file-preview.md) 的宽度规则按扣除两侧留白后的卡片净宽计算。目录切换和窄窗浮层沿用现有规则。 |
| 输入及状态 | 沿用现有输入框和内部控件、消息和工具行、运行状态的位置和样式。阅读列、草稿和焦点继续走现有布局与会话状态。 |
| 滚动条 | 左侧会话列表始终隐藏滚动条，支持滚轮和触控板上下滚动。对话、文件预览和代码块统一采用约 3 pt 的低对比滑块，轨道融入背景。默认滚动时短暂显示，静止后淡出。沿用 macOS 滚动条显示偏好与增强对比度行为，保留现有滚动和拖动能力。 |

## 工程映射

- 在 [WorkbenchView](../../Zivvi/Features/Workbench/WorkbenchView.swift) 的详情容器设置共同外框，复用现有文件面板布局与分隔线。顶栏与侧栏底色沿用 [ZivviTheme](../../Zivvi/DesignSystem/ZivviTheme.swift) 的同一语义色。
- 复用 [ComposerView](../../Zivvi/Features/Composer/ComposerView.swift) 和现有阅读列规则。[WorkbenchScroller](../../Zivvi/DesignSystem/WorkbenchScroller.swift) 复用原生滚动容器，仅自绘滑块和交互中的轨道。首轮实现使用 3 pt 常态宽度，系统增强对比度下增至 6 pt 并强化颜色。
- 原生验收重点核对文件面板开关、拖动和窄窗切换，确认卡片边缘与滚动条互不遮挡。对照浅色、深色、增强对比度及系统滚动条偏好，核对可滚动性和滑块淡出。系统设为「始终显示滚动条」时，确认左侧长会话列表可上下滚动和自动定位，静止和滚动时均隐藏滚动条。设计稿仅覆盖浅色的关闭与停靠两种状态。

用户在 2026-11-24 确认采用 r06。两张定稿图均为静态设计稿，来自同一轮修订。作者核对确认 r06 与 r05 的像素差异局限于滚动条区域。Vistra 0.1.5，产物契约 1。
