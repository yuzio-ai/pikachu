# 会话模型选择 · Agent、模型与推理强度

**2026-11-23 定稿。** 输入框的「智能体与模型」浮层按 **智能体 → 模型 → 推理强度** 排列。「收藏／全部」筛选所选智能体的目录。标识及可见性规则沿用[服务商设置](provider-settings.md)。

## Agent

- 顶部选择当前会话可用的 coding agent，显示完整名称及 Logo。无 Logo 时使用名称前两个大写字母。有多个候选时可用名称和标记区分。只有一个可用 agent 时直接显示当前值。
- 首次发送前，尚未绑定的草稿可选择 Agent。已绑定的会话继续支持在当前 Agent 内换模型。会话空闲后，可使用「切换智能体…」进入接力，在同一对话选择目标 Agent 并预览交接内容。 [会话接力](session-agent-handoff.md)
- 接力预览保留文本草稿与附件，从目标 Agent 读取模型及推理档位。点击「切换」后保存目标及交接内容，下次发送时启动目标。模型偏好按 Agent、供应商和模型 ID 归属。
- 选项来自已启用的 ACP 智能体。 [当前装配](../../Zivvi/App/AppSettings.swift) · [多运行时设计](../../DESIGN.md)

## 模型

- 在所选 agent 内提供「收藏／全部」。有可见收藏时默认展示收藏，否则展示全部可见模型。输入搜索词默认临时切到全部，可手动切回收藏收窄结果。清空查询恢复查询前的范围。搜索匹配模型名、供应商名和完整模型 ID。
- 已隐藏模型可在设置中搜索并恢复。会话浮层保留仍可用的当前或暂选模型的既有例外。筛选和查询只改变目录的显示。选择被查询临时滤掉时，推理区显示所选模型名称，保留待保存值。
- 模型名占据整行主信息，供应商 Logo 和第二行名称表明来源。长名称或同名条目仍可通过键盘、悬停和 VoiceOver 获取完整 ID。星标指示已收藏，勾标记暂选。Agent 自行决定模型时，用只读说明替代选择列表。
- 已确认有快照日期的模型，在名称右侧用浅底、细边和轻阴影的胶囊显示日期。已知完整日期时显示 `YYYY-MM-DD`，仅确认月日时显示 `MM-DD`。图中 `10-17` 是月日示意。完整模型名和 ID 继续参与搜索及辅助功能朗读。仅在目录元数据或该供应商已确认的命名规则能确定日期时拆分。普通版本号和含义不明的数字保留在原名中。
- 当前日期显示使用 OpenAI 的完整日期后缀及 Token Plan 已列出的三个 DeepSeek 型号；Token Plan 的月日来自对应型号后缀。 [OpenAI 快照示例](https://developers.openai.com/api/docs/models/gpt-4o) · [Token Plan 型号标识](https://help.aliyun.com/zh/model-studio/qwen-code)

## 推理强度与保存

- 使用分段滑块样式。每个段对应一个运行时提供的离散档位，点击或按方向键切换，选中段的滑块移动。具体档位由所选智能体提供。「默认」表示沿用运行时默认，其含义在无障碍标签中读出。
- 选择模型后重新读取它支持的档位。仅恢复该模型已保存且仍支持的档位，其余情况使用「默认」。晚到结果仅在 agent、模型及查询轮次均匹配时应用。没有可调档位时显示只读「运行时默认」。加载、失败和重试放在推理区。推理配置准备完成后才能保存。
- 「取消」丢弃本次暂选。「保存」一次提交全部选择。原有会话操作保护、待应用提示和保存失败重试继续适用。保留输入框模型按钮的锚点、快捷键与来源提示，按钮的辅助功能名称和无摘要时的提示采用「智能体与模型」。

## 宽窄布局

浮层顶部直接显示智能体选项，随后是搜索、筛选和模型列表。「智能体与模型」作为浮层的辅助功能名称，两个分组各有辅助功能标签。

- 模型浮层优先在输入框的模型按钮上方展开，宽度随输入框可用空间收缩。模型列表按内容高度收起留白，超出六行时滚动。会话级选择的来源通过模型按钮的辅助功能提示提供。
- 智能体、「收藏／全部」与推理强度均为组内互斥的单选分段控件，复用同一视觉组件。底轨、圆角、选中滑块、前景色和焦点样式采用同一组设计值。智能体段内含 Logo 与名称，窄窗筛选段和推理档位段使用文字。各组宽度按内容分配。
- 宽窗搜索与收藏筛选同行，「推理强度」标签与分段滑块同行。
- 窄窗同一行从左到右为搜索、「收藏」「全部」。搜索框占据剩余宽度。筛选只显示文字，模型行仍用星标表示收藏状态。推理强度标签与档位同一行，通过缩短档位的水平内边距释放宽度，字号与点击区域沿用项目规范。
- 窄窗使用组间留白区分智能体、模型、推理强度和底部操作，移除贯穿正文的静态分割线。搜索框和控件自身边界继续表达输入、选中及焦点状态。
- 当窗口与字号组合使档位无法单行容纳时，采用同一数据源的档位菜单。搜索与筛选单行优先，在本地化或字号导致搜索框无法正常使用时才换行。高度紧张时滚动模型目录，保留 Agent、推理和底部操作。缩放保留 Agent、查询、暂选、档位、滚动和逻辑焦点。

## 实施与验收

沿用 Composer 的原生浮层。先实现当前 Agent、模型范围与分段档位界面，再随后端接入验证多 Agent 草稿选择。实际装配须从 agent 及模型能力读取目录和档位。独立审查覆盖入口、配置读取、保存、权限和焦点。 [输入区入口](../../Zivvi/Features/Composer/ComposerView.swift) · [现有浮层](../../Zivvi/Features/Settings/ModelConfigurationPanel.swift)

| 验收项 | 方法与证据 |
|---|---|
| MP-01 · Agent 与偏好 | 用多 Agent 合成 ACP 夹具和获授权的真实 ACP Agent 核对可用选项、Logo 回退、切换时保留草稿附件及独立的模型和档位。已绑定会话的切换走接力流程。 |
| MP-02 · 目录与搜索 | 覆盖同名供应商、日期快照、一般版本号、含义不明的数字、长 ID、空收藏、当前隐藏模型，以及切换到其他 agent 后的查询。核对完整原名仍可搜索与朗读。 |
| MP-03 · 档位与保存 | 用档位不同的两个模型、无档位、读取失败、异步晚到、保存失败及会话切换夹具核对选项和回退。原生核对点击、方向键、取消、一次保存和已配置会话的待应用路径。 |
| MP-04 · 原生布局 | 从输入框打开，在最窄、默认、大窗和拖动切换时核对窄窗的两处同行、搜索宽度、留白层级、列表滚动和底部操作。核对三组分段控件的选中及焦点样式与组内单选。覆盖中英文、浅深外观、大字号、键盘和 VoiceOver。验证极端宽度下控件回退。 |
