# 会话交接展开态 · r07

2026-11-25 · 已定稿

会话交接保留 [r03 的发送前编辑器和时间线位置](../session-switch-presentation.md)。本轮调整送达后的展开区，突出最近请求和文件清单。用户可以直接进入右侧项目文件预览。

![展开态及打开右侧文件预览后的布局示意](delivered-context-r07.png)

## 内容与操作

- 交接分隔行默认收起，位于首次送达的用户消息前。点击原位展开。「上次请求」和「相关文件」／「文件改动」使用同一级 `headline` 和主文字色，小节之间以留白和细分隔线区分。「上次请求」展示交接时保存的用户正文，气泡沿用「继续」用户消息的底色、12 pt 圆角、字号和内边距。气泡对齐标题左缘，按正文尺寸增长并在可用宽度内换行。完整保留段落，支持选择复制。标题右侧的文件数量使用次要字色。
- 文件区显示前三项。摘要和完整列表里的可打开文件名使用 Markdown 链接样式，采用蓝色正文和下划线。文件行移除灰底、路径副行、阴影和箭头。完整路径可通过悬停提示、辅助功能和「复制路径」读取。结构化记录右侧保留可用的增删统计。「查看全部 N 个」保留文案及箭头，打开完整列表。
- 点击文件名直接打开右侧预览。键盘焦点有独立描边，VoiceOver 提供「在右侧预览」动作说明。右侧面板收起时自动打开，已有同路径标签页时切换到该页。查看全部列表中的文件打开成功后收起列表。打开的是会话工作目录中的当前文件内容。
- 已知无法打开的文件名使用次要文字色，并显示原因。已知删除的项显示「已删除」。已知在工作目录外或路径无法确定的项显示「无法在项目文件中打开」。这些行提供完整路径与复制路径。点击后发现文件不存在、权限失效、格式不支持或工作目录不可用时，在操作位置提示原因并保留交接展开状态。打开动作以右侧项目文件面板为目标。
- 移除展开区中的「查看完整交接正文」和相应弹层。已发送的交接内容继续作为历史送达数据。无法从旧记录可靠还原字段时，显示简短文本预览。上次请求缺失时，有可识别回复则显示回复摘要。发送前依照 r03 编辑请求、勾选整场会话中已记录的改动并保存。

## 实施方案

`TranscriptView` 负责展开区、文件行及打开状态。沿用同一文件行组件表达摘要、完整路径和可打开状态，覆盖冻结段、活跃段及旧文本记录。上次请求取自已送达记录中最近请求字段或旧格式可识别的请求段落。英文标题采用 “Previous request”。请求气泡复用对话消息的样式，文件名复用会话 Markdown 的链接配色和下划线，深浅色跟随 `MarkdownColors.link`，点击通过既有文件预览入口处理。只在展开时构造摘要，完整列表按需加载。右侧预览以当前对话绑定的工作目录为访问范围。绝对路径可直接定位，相对路径使用随文件改动保存的绝对基准。历史记录缺少可确定的基准时显示原因，并保留路径供复制。重命名按最后记录的目标路径查找。路径规范化、工作目录归属与读取沿用 `ProjectFilePath` 和 `ProjectFilesReader` 的验证。

`NativeTranscript`、`WorkbenchView` 与文件面板模型复用现有右栏打开、标签页选中和请求取消逻辑。普通对话文件链接的现有入口可回退外部应用。交接文件入口须在同一栏处理成功及失败，按实际结果在原操作位置反馈。只有当前会话、当前工作目录中的最新请求可以激活右栏、更新标签页和提示。开始实施时固定包含此前 r03 视觉整改的新候选，对受影响应用词条和已经失去调用方的交接弹层同步清理。

交接入口使用右栏专用结果处理。用户能在原对话旁查看文件，打不开时也可看到原因。实施时补齐右栏无法预览时的行级反馈。
