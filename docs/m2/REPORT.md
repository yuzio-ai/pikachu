## 实现

| 模块 | 职责 |
|---|---|
| AgentRuntimeCore | 中立的历史条目、会话文件引用、模型与思考配置接口 |
| PiRuntimeAdapter | Pi v3 只读发现与当前分支投影；恢复取消检查、会话 ID / 文件核对、模型查询及有效配置读回 |
| OrchestrationCore | 分离查看与执行；每会话草稿 / 恢复草稿 / 提交状态；全局单执行槽位、跨会话切换和迟到事件隔离 |
| WorkspacePersistence | SwiftData actor；版本化中立元数据文档、显式保存和过期写入防护；关闭 CloudKit |
| PikachuApp | 最近项目与会话列表、重新定位、只读历史、全局返回 / 停止、切换确认及模型设置面板 |

SwiftData 仅保存项目、引用、配置、选择、草稿和最小提交记录，没有保存第二份消息或工具历史。领域类型不引用 SwiftData 或 SwiftUI。Pi 原始文件是对话真实来源；历史缓存仅在内存中。

每个项目使用稳定 UUID，路径是可更新的位置属性。本地 Session UUID、Pi Session ID 与进程实例 ID 分开。新会话先是本地条目，首次激活才创建进程；Pi 尚未写出历史文件时仍保留待初始化语义。已确认存在的历史若丢失，则保留原绑定、报错并禁止继续发送，不退化成新空会话。

## 运行与恢复规则

- 浏览其他项目或历史只调用历史读取接口；输入与草稿始终归属查看对象。实时事件仍进入原执行会话，不拼接到其他历史视图。
- 变更执行目标时统一使用新的受管进程。旧任务忙时先保留目标草稿，要求明确确认；停止及清理失败则保留原槽位，不建立目标进程。
- M1 的 clear_queue → 保留返回草稿 → abort → 状态确认流程保留。切换与退出再核对监督终态。恢复草稿与编辑框分开，手动放回时追加而非覆盖。
- 发送前持久化本地关联 UUID 与意图，保存失败不发送。接受回执只代表接受，不代表完成；已确认完成或退回草稿的重复提交正文及时清理。
- 点击发送时固定内容与模式。等待激活 / 连接期间的新编辑保持为草稿，不替换原提交，也不被发送后的清空覆盖。
- 重启只恢复索引、历史、配置与已保存草稿；不连接、不推理、不重发、不重排旧队列。未决输入保留关联 UUID、接受情况与“结果待核实”，不靠相同文本消除不确定性。用户核对后才解除发送限制。
- 编辑约 250 ms 合并保存；清出的内容尽快保存，停止、切换、退出时显式保存。保存失败保留内存内容并阻止新任务，退出保存失败则保持 App 打开。尚未持久化的编辑不保证在 SIGKILL 后恢复。

## Pi 1.5.2 的目录移动边界

实查已安装版本的 `agent-session-runtime.js`：RPC `switch_session` 调用 `SessionManager.open(sessionPath)`，并以该 Session 的 CWD 重建服务，没有暴露 `cwdOverride`。仅修改 Swift Process 的启动目录不能覆盖恢复后的工具目录。

因此重新定位项目后保留稳定项目 / 会话标识、历史和草稿；旧会话可只读查看，但在原历史 CWD 与当前位置不符时阻止续跑。新位置可新建会话执行。此限制在协调器和适配层均检查，适配层在启动 Pi 前拒绝错误目录；没有改写旧文件、创建隐式副本、添加 TypeScript 桥或默默在旧目录执行。

验证既包含错误位置被拒绝，也包含新会话中真实 Bash / Node 写出 CWD，再由独立文件读取核对当前位置。该边界已同步到 DESIGN.md 与 README，不将旧会话跨目录续跑列为已实现。

## 保留的监督边界

M0 的 C 进程检查、ProcessIdentity、RPC 客户端和独立 supervisor **全部保持 M1 冻结指纹一致**。没有修改所有权判断、宿主死亡检测、信号升级、超时或 fail-closed 策略。Pi 仍通过 bundle 内置的 `m0-supervisor` 启动。

适用边界继续以 [M0 报告](../m0/SUPERVISION.md#3-适用边界) 为准：同用户可检查、继承标记或已登记谱系的后代；不是系统沙箱，不保证主动去标记后逃离谱系、提权或整个宿主及监督同时被杀死的清理。未验证公证分发、App Sandbox、系统 Force Quit 或外部进程同时执行同一历史文件。

## 当前限制

- 只支持 Pi 1.5.2、v3 会话格式；未知版本和损坏文件不自动迁移。单历史文件读取上限 128 MiB；大文件 / 长列表性能仍待 M3。
- 发现范围为标准 Pi 目录、原 M1 目录和当前 App 会话目录；自定义目录可通过 `--sessions` 指定。新增外部会话通过打开项目或“刷新”发现。
- 新位置不能直接续跑旧 CWD 的 Pi 历史。改为只读旧会话与显式新建，没有改变稳定项目身份。
- 已知 Extension UI 仍取消，自动扩展和技能仍关闭。没有引入完整原生扩展弹窗、用量统计、执行审批或 Subagent。
- 未更改 M1 性能目标；记录保留、背压、完整辅助功能和量化原生性能属于 M3。本轮没有将 Phase 1 整体或公开发布标为完成。
- 未提交或推送 Git。M0、M1 原有证据没有覆盖；导出仅包含本轮受控夹具与脱敏检查结果，不包含认证文件或工作台数据库。
